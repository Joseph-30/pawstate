PawStateReal-Time Canine Emotion & Behaviour IntelligenceSTARTUP ROADMAPFrom Contest Prototype → Commercial ProductVersion 1.0  |  2026Prepared by: Joseph P George, Kasinath Salim, Evan George VargheseCONFIDENTIAL — INTERNAL USE ONLYExecutive SummaryPawState began as a TRON Programming Contest 2026 entry — a collar-mounted node running μT-Kernel 3.0 that classifies canine emotional states in real time using a TinyML model on embedded hardware. The contest was the proof-of-concept phase.The opportunity is larger. There are an estimated 900 million dogs worldwide, and the global pet wearables market is projected to reach $4–6B by 2030. No company currently offers real-time, embedded emotional state classification for dogs. The commercial pet-tech market (Whistle, Fi, Tractive) is entirely focused on GPS and step counting — a completely different problem.PawState's moat is threefold: a proprietary labelled IMU dataset that grows with every deployed device, an RTOS-based interrupt architecture that is novel in the consumer pet-tech space, and a founding team that has already built and tested the core technology on real hardware. This document is the roadmap from where we are today to a fundable, scalable company.1.  Company Overview & VisionWhat PawState DoesPawState is a collar-mounted embedded intelligence node. A dog wearing a PawState collar has its motion continuously sampled at 50 Hz by a 6-axis IMU. An RTOS (μT-Kernel 3.0) schedules four prioritised tasks that transform raw sensor data into a real-time classification of the dog's emotional and behavioural state: Resting, Walking, Playing, Anxious Pacing, or Alert Freeze. State transitions and anxiety spikes are pushed to the owner's phone via BLE within 30 ms.The Problem We're SolvingDogs cannot self-report distress. Their owners, vets, and caregivers rely on observational cues that require physical presence. Separation anxiety affects an estimated 14–20% of dogs globally and is the leading cause of owner surrender to shelters. Post-surgery recovery, age-related cognitive decline, and chronic stress all produce behavioural signatures that are currently invisible to caregivers who aren't in the room.Existing commercial wearables don't help. They count steps. PawState classifies emotional states — and it does so in real time, on-device, with hard latency guarantees.Vision"To become the emotional health platform for companion animals — starting with the dog collar, expanding to a longitudinal behavioural health record that informs veterinary care, pet insurance, and owner decisions."2. Build the proof of concept. Document everything.This phase is already underway. The micro:bit v2 has been approved and is being shipped. The primary deliverables are a working RTOS firmware running all four tasks on μT-Kernel 3.0, a trained TinyML classifier with >80% accuracy on the five behavioural classes, a BLE-connected phone notification for anxiety spikes, and a real-dog test video.The secondary deliverable — equally important for the startup — is a clean, well-documented GitHub repository. Every architectural decision, every dataset citation, every RTOS configuration choice should be documented publicly. This is how you build credibility before you have a product.Firmware: μT-Kernel 3.0 task scheduler, IMU sampling, feature extraction, TF-Lite Micro inference, BLE loggerML: Python training pipeline, INT8 quantisation, model export to TF-Lite, test accuracy reportHardware: micro:bit in collar sleeve, tested on real dog across at least 3 activity typesDocumentation: GitHub README, architecture diagram, dataset methodology, demo videoPhase 1 — Foundation  (Nov 2026–Feb 2027)Goal: Establish the open-source community, expand the dataset, align as a founding team.After the contest, the first priority is not building a product — it's building the asset that makes the product defensible: data. First real paying users. Validate willingness to pay.Phase 2 is about making PawState something a real dog owner would actually put on their dog and pay for. Phase 2 requires a dedicated PCB.Hardware v2 Spec (Custom PCB)SoC: Nordic nRF52840 (Cortex-M4F, 1 MB flash, 256 KB RAM — more headroom than nRF52833 for the ML model)IMU: Bosch BMI270 (6-axis, ultra-low power, optimised for wearables — better than LSM303AGR for this use case)Battery: 200–300 mAh LiPo with USB-C charging, target >7 day battery life at full operationForm factor: 30mm × 22mm × 8mm — fits inside a standard D-ring collar sleeveBLE: onboard antenna, BLE 5.0, target 30m range in open environmentMobile App v1React Native (iOS + Android from single codebase)Real-time state display: current behavioural state with confidence scorePush notifications for anxiety spikes24-hour timeline view of state historyFree tier: real-time alerts. PawState is an upgrade, not a new category for them.Segment 3 — Veterinary Clinics & Boarding Facilities (B2B)Clinics managing post-surgical recovery, anxiety cases, or boarding multiple dogs benefit from continuous objective monitoring. PawState's dashboard provides data they currently don't have.Competitive LandscapeCompetitorWhat They DoGap We FillMarketWhistle / Fi / TractiveGPS + step countNo emotional states, no RTOS, no real-time alertsMass marketPetpaceVital signs (HR, temp)No motion-based emotion, no embedded MLVet clinicsDogPhone / InvoxiaAudio + GPSNo IMU behavioural analysisConsumerPawState (us)IMU emotional states + RTOS real-time alerts + TinyMLFirst mover in real-time canine emotion classificationAll segments5.  Product & Technology StrategyCore Technology Stack (Current → Target)Embedded firmware: μT-Kernel 3.0 RTOS → custom RTOS optimisation for nRF52840 in Phase 2ML model: TF-Lite Micro INT8 FC network → per-breed fine-tuning layer + continuous on-device learning in Phase 4Connectivity: BLE 5.0 → optional LTE-M / NB-IoT variant for dogs in large outdoor spaces (Phase 4)Mobile: React Native → native iOS/Android in Phase 4 for performanceBackend: Firebase (Phase 2) → custom data platform with anonymised dataset API (Phase 4)Hardware Roadmapv0: micro:bit v2 (contest prototype) — development only, not for consumersv1: Custom PCB (nRF52840 + BMI270 + LiPo) — Phase 2 beta and D2C launchv2: Miniaturised form factor, waterproof (IP67), optional haptic feedback for training integration — Phase 4v3: Multi-sensor (add HR/temp via PPG) for expanded health monitoring — Phase 5Open Source StrategyThe contest firmware and ML training pipeline will be released as open source (MIT licence) after the contest. This is not charity — it is a deliberate strategy. Open-source credibility in the embedded ML space attracts contributors, generates labelled data donations, and builds the brand among developers and veterinary researchers before any commercial product ships. The proprietary assets (trained model weights, production firmware, dataset) remain closed.6.
